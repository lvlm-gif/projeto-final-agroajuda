# AgroAjuda 🌱

O **AgroAjuda** é um aplicativo Android desenvolvido para conectar pequenos agricultores a serviços de assistência técnica especializada. O projeto busca mitigar as dificuldades de deslocamento e comunicação, facilitando o acesso a orientações fundamentais para o sucesso da produção agrícola.

## 🎯 Objetivo e Problema
Muitos pequenos agricultores enfrentam barreiras geográficas e burocráticas para obter suporte técnico para suas plantações. O AgroAjuda resolve esse problema ao centralizar e simplificar a solicitação de assistência, permitindo que o produtor rural receba ajuda de forma rápida e eficiente diretamente pelo seu smartphone.

## 📱 Funcionalidades
*   **Gestão de Acesso:** Cadastro e login seguro para agricultores.
*   **Solicitação de Assistência:** Interface intuitiva para descrever e enviar pedidos de suporte técnico.
*   **Catálogo de Serviços:** Visualização detalhada das informações e tipos de assistência disponíveis.
*   **Histórico e Acompanhamento:** Organização e monitoramento do status das solicitações realizadas.
*   **Canal de Comunicação:** Facilitação do contato entre o agricultor e o profissional técnico.

## 🛠️ Tecnologias e Ferramentas
O projeto foi construído utilizando as melhores práticas modernas de desenvolvimento Android:

*   **Linguagem:** [Kotlin](https://kotlinlang.org/)
*   **Interface UI:** [Jetpack Compose](https://developer.android.com/jetpack/compose) com Material Design 3
*   **Arquitetura:** MVVM (Model-View-ViewModel)
*   **Banco de Dados Local:** [Room Persistence Library](https://developer.android.com/training/data-storage/room)
*   **Consumo de API:** [Retrofit](https://square.github.io/retrofit/) & Gson
*   **Gerenciamento de Dependências:** Gradle (Kotlin DSL) com Version Catalogs (`libs.versions.toml`)
*   **Versionamento:** Git e GitHub

## 🚀 Como Executar o Projeto
1.  Certifique-se de ter o **Android Studio** instalado (versão Ladybug ou superior recomendada).
2.  Clone este repositório:
    ```bash
    git clone https://github.com/seu-usuario/projeto-final-agroajuda.git
    ```
3.  Abra o projeto no Android Studio.
4.  Aguarde a sincronização do Gradle.
5.  Execute o aplicativo em um emulador ou dispositivo físico com **Android 7.0 (API 24)** ou superior.
