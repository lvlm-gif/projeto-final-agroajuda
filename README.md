AgroAjuda 🌱

O AgroAjuda é um aplicativo desenvolvido para auxiliar pequenos agricultores a encontrar e solicitar assistência técnica de forma mais prática, reduzindo a necessidade de deslocamento e facilitando o acesso a informações e serviços para a produção agrícola.

🎯 Objetivo

O projeto tem como objetivo aproximar pequenos agricultores de serviços de assistência técnica, oferecendo uma forma simples e acessível de solicitar ajuda para suas atividades agrícolas..

📱 Funcionalidades

* Cadastro e acesso de usuários;
* Solicitação de assistência técnica;
* Visualização de informações sobre os serviços;
* Organização das solicitações;
* Comunicação entre agricultores e profissionais de assistência técnica.

🛠️ Tecnologias utilizadas

* Android Studio
* Kotlin
* Room
* Retrofit
* Git e GitHub
