# Prompt: Listar solicitações na tela de status

## Objetivo
Modificar a `TelaStatusSolicitacao.kt` para exibir uma lista de solicitações de assistência técnica e permitir a visualização do status detalhado de cada uma.

## Requisitos solicitados
- Exibição de uma lista de solicitações com ID, Profissional, Atendimento, Data e Status.
- Alternância entre a visualização de listagem e detalhes ao selecionar um item.
- Uso de dados fictícios locais (não persistentes).
- Interface simples e funcional usando componentes básicos do Jetpack Compose.
- Manutenção da navegação de retorno e para a tela inicial.
