# Prompt: Nova Tela de Status da Solicitação

## Objetivo
Implementar a interface visual da tela de status de solicitação no AgroAjuda, permitindo ao usuário acompanhar o progresso de um pedido de assistência técnica.

## Requisitos solicitados
- Tela organizada com título "Status da solicitação".
- Exibição de dados ilustrativos: nome do profissional, tipo de atendimento, data e ID da solicitação.
- Indicador visual de progresso (timeline) com 4 etapas:
  1. Solicitação enviada.
  2. Aguardando resposta do profissional.
  3. Solicitação aceita.
  4. Atendimento concluído.
- Botão para retornar à tela inicial.
- Manutenção da identidade visual (cores #F7F7F2, #183D27, #397D45).
- Sem implementação de lógica de banco de dados ou backend.
