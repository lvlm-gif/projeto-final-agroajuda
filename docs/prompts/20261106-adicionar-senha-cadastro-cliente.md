# Prompt: Adicionar campo de senha no cadastro do cliente

## Objetivo
Incluir um campo de criação de senha na tela de cadastro de clientes do AgroAjuda, garantindo a funcionalidade de ocultar/mostrar o texto e mantendo o padrão visual minimalista.

## Requisitos solicitados
- Adicionar o campo "Senha" ao formulário de cadastro de cliente.
- Utilizar `PasswordVisualTransformation` para ocultar os caracteres.
- Implementar a opção de alternar entre "Mostrar" e "Ocultar" utilizando botões de texto simples.
- Validar o preenchimento obrigatório da senha no envio do cadastro.
- Manter o design cru (fundo branco, textos escuros, sem decorações).
- Não alterar o banco de dados.

## Instruções Adicionais
- Garantir consistência com a tela de login.
- Utilizar componentes básicos do Jetpack Compose.
- Registrar a atividade seguindo os padrões de documentação da equipe.
