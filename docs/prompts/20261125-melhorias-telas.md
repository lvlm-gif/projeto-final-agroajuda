# Prompt: Melhorias nas telas do AgroAjuda

## Objetivo
Realizar melhorias na interface do usuário para aumentar a visibilidade de funcionalidades importantes, especificamente o acesso ao status das solicitações, garantindo que o usuário identifique facilmente onde consultar o andamento de seus pedidos.

## Requisitos da Melhoria: Indicação do Status da Solicitação
- **Localização**: Tela Principal (onde se encontra o ícone de informação ⓘ).
- **Alteração**: Adicionar uma pequena nuvem de mensagem ou balão de fala próximo ao ícone.
- **Conteúdo**: Texto curto "Ver status da solicitação".
- **Visibilidade**: Tornar o acesso mais evidente, resolvendo o problema de o ícone estar muito discreto.
- **Preservação**: Manter o ícone original, sua funcionalidade de clique e o alinhamento geral da tela.

## Restrições
- Modificar apenas os arquivos de UI necessários.
- Não alterar o banco de dados (Room, entidades, DAOs, repositórios).
- Não modificar ViewModels sem autorização.
- Não realizar mudanças gerais de identidade visual (cores, design global).
- Seguir o padrão de design funcional e simples do projeto.
