# Prompt: Adicionar acesso à tela de status da solicitação

## Objetivo
Adicionar um ponto de acesso na tela inicial para que o usuário possa navegar até a tela de status da solicitação.

## Requisitos
- Adicionar um ícone de navegação no canto superior direito do cabeçalho da tela inicial.
- O acesso deve levar à `TelaStatusSolicitacao.kt` utilizando a rota já configurada.
- Manter o layout e os estilos originais da tela inicial.
- Não alterar funcionalidades existentes ou o banco de dados.
