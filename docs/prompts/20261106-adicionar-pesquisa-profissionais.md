# Prompt: Adição de Barra de Pesquisa na Tela Principal

## Objetivo
Implementar uma funcionalidade de busca na tela inicial do AgroAjuda para permitir que o agricultor encontre profissionais específicos por nome ou especialidade.

## Requisitos solicitados
- Adicionar uma barra de pesquisa funcional.
- Filtragem por nome do profissional.
- Filtragem por especialidade.
- Design simples e básico, seguindo o padrão atual das telas.
- Não alterar o banco de dados.

## Instruções Adicionais
- Utilizar `OutlinedTextField` com ícone de pesquisa.
- A lista de profissionais deve ser atualizada em tempo real conforme a digitação.
- Manter a interface limpa e organizada dentro da estrutura existente.
