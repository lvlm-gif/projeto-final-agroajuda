# Prompt: Implementação da Tela de Login — AgroAjuda

## Objetivo
Criar uma tela de Login básica e funcional para ser o ponto de entrada do aplicativo AgroAjuda, permitindo a navegação para a tela principal e para o cadastro.

## Requisitos solicitados
- Implementar a interface visual crua e simples.
- Campos de E-mail e Senha.
- Botão "Entrar" para navegar até a Home.
- Opção para navegar até a Tela de Cadastro.
- Definir como rota inicial no NavGraph.
- Respeitar a arquitetura MVVM e não alterar o banco de dados.

## Instruções Adicionais
- Utilizar Kotlin e Jetpack Compose.
- Manter o padrão de código e pacotes do projeto.
- Não implementar lógica de autenticação real.
