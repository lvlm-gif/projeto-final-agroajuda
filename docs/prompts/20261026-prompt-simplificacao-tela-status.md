# Prompt: Simplificação da tela de status da solicitação

## Objetivo
Remover toda a estilização avançada, cores decorativas e elementos visuais complexos da `TelaStatusSolicitacao.kt`, deixando a interface puramente básica, crua e funcional.

## Requisitos solicitados
- Remover cards elaborados, sombras, animações e ilustrações.
- Utilizar apenas componentes básicos do Jetpack Compose (Text, Button, Column, LazyColumn).
- Manter a lógica de listagem e visualização de detalhes com dados fictícios.
- Preservar a navegação e o cabeçalho funcional.
- Não realizar qualquer alteração no banco de dados.
